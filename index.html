¿Qué es Python?

Python es un lenguaje de programación fácil de entender, por eso lo estamos usando para aprender a programar. Fue creado por Guido van Rossum y se usa mucho porque su código es corto y se lee casi como si fuera español o inglés normal.

Con Python se pueden hacer páginas web, juegos simples, programas para organizar datos, entre otras cosas.

Instalación

Para programar en Python primero hay que instalarlo desde la página oficial python.org. Después de instalarlo, se puede comprobar que funciona escribiendo esto en la terminal: 

python --version

Yo lo estoy usando junto con Visual Studio Code, que es un editor de código que nos recomendó el profesor.

Variables

Una variable sirve para guardar un valor. En Python no hay que decir de qué tipo es la variable, Python lo detecta solo. 

nombre = "Pedro"
edad = 19
print(nombre)
print(edad)

Tipos de datos

Estos son los tipos de datos básicos que vimos en clase:

Tipo Ejemplo
int (número entero) 10
float (número decimal) 3.5
str (texto) "Hola"
bool (verdadero/falso) True o False

Operadores

Los operadores sirven para hacer operaciones matemáticas o comparaciones:

+   suma
-   resta
*   multiplicación
/   división
==  comparar si son iguales
>   mayor que
<   menor que

Condicionales (if)

Sirven para que el programa tome decisiones. Este ejemplo revisa si una persona es mayor de edad: 

edad = 19

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

Bucles (for y while)

Los bucles se usan para repetir algo varias veces.

for i in range(5):
    print(i)
contador = 0
while contador < 3:
    print("Hola")
    contador = contador + 1

Listas

Una lista guarda varios valores juntos. En clase practicamos agregando y mostrando elementos de una lista. 

frutas = ["manzana", "banana", "uva"]
print(frutas[0])
frutas.append("pera")
print(frutas)

Funciones

Una función es un bloque de código al que le podemos poner nombre y usar varias veces sin escribirlo de nuevo. 

def saludar(nombre):
    print("Hola " + nombre)

saludar("Pedro")
